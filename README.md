# COVID-19 Data Analysis using SQL & Tableau

## Project Overview

This project analyzes COVID-19 trends across 10 countries using SQL Server for data analysis and Tableau for interactive visualization. It focuses on understanding confirmed cases relative to population, case fatality rates, vaccination progress, and overall COVID-19 trends through SQL queries and interactive analytical dashboard.

## Objectives

- Analyze COVID-19 cases and deaths over time
- Compare confirmed cases relative to population across countries
- Evaluate case fatality rates
- Track vaccination progress and coverage
- Build an interactive Tableau dashboard for comparative analysis

## Tools & Technologies

- Microsoft SQL Server
- Tableau Public
- Microsoft Excel

## Dataset

A curated COVID-19 dataset containing:
- 10 Countries
- 80 country-date records in each dataset
- COVID Cases & Deaths
- Vaccination Data
- Population & Demographic Indicators

## SQL Analysis

The project includes SQL queries for:

- Case Fatality Rate Analysis
- Confirmed Cases as % of Population
- Continent-wise Case Fatality Rate
- Vaccination Progress Analysis
- CTEs
- Window Functions
- Temporary Tables
- Joins

## Tableau Dashboard

The dashboard includes:

- Total Confirmed Cases KPI
- Total Deaths KPI
- Countries Analyzed
- Latest Reporting Date in Dataset
- Cases Trend
- Vaccination Trend
- Top Confirmed Cases as % of Population
- Top Case Fatality Rate
- Top Vaccination Coverage

## Key Insights

- Confirmed cases as a percentage of population varied across countries.
- Vaccination activity increased across the selected reporting periods.
- Case fatality rates differed across countries and continents in the selected reporting data.
- The interactive dashboard enables comparison of COVID-19 metrics across countries and reporting periods.
